
# Silver: 정제된 30분 관측값 생성
15분 데이터를 동일한 굴뚝, 동일한 측정 항목, 동일한 30분 슬롯으로 그룹화한다.
유효한 측정값 2개가 확보된 경우 평균을 계산한다.
상태코드, 측정 단위 및 기준치의 유효성을 검증한다.
정상적인 측정값은 정제된 관측값으로 활용하고, 비정상·결측·불량 데이터는 제외하거나 사유를 보존한다.
기준 대비 비율인 ratio_pct를 계산한다.
현재 구현은 15분 원본 데이터에서 동일한 굴뚝과 항목에 해당하는 30분 슬롯을 구성하고, 유효한 값 2개가 있는 경우 평균을 계산하여 ratio_pct를 생성하는 구조다.

# ML-ready: 모델 학습용 Feature 및 Label 생성

과거 측정값을 활용해 Lag Feature를 생성한다.
최근 3시간의 평균과 표준편차를 계산하여 시계열 특성을 반영한다.
시간, 월, 요일 정보를 Sin/Cos 형태로 변환하여 주기적인 패턴을 표현한다.
60분 뒤의 실제 비율과 진입 여부를 Label로 생성한다.
Feature와 Label의 유효성을 구분하여 학습에 사용할 데이터를 결정한다.

예측 시점 이후의 정보가 입력 Feature에 포함되지 않도록 데이터 누수를 방지하는 것이 중요하다.
미래 정보 누수를 방지하면서 모델 학습에 필요한 Feature와 Label 구성

# 검토할 내용
① 15분 → 30분 집계	: 두 측정값이 모두 유효하지 않으면 어떻게 처리하는가? 한 개만 유효한 경우는 제외하는가?
② 기준치 적용	: 기준 변경 시점을 어떻게 반영하는가? 기준치가 변경되면 변경 전후 데이터를 어떻게 구분하는가?
③ 결측 및 품질 정보	: Silver에서 제외한 데이터의 사유와 품질 정보가 별도로 보존되는가?
④ 미래 예측 : 60분 후 예측을 위해 Label을 생성할 때, 현재 시점 기준으로 정확히 60분 후의 측정값을 연결하고 있는지?
             특히 측정 데이터가 누락되거나 시간 간격이 일정하지 않은 경우에도 정확한 미래 시점을 찾아 Label을 생성하는 방법의 고민이 필요합니다.
