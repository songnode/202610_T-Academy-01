# CEMS 데이터 처리 및 ML 학습 데이터 설계 검토

## 1. Silver: 정제된 30분 관측값 생성

Silver 단계에서는 Bronze에 저장된 15분 단위 원본 데이터를 30분 단위의 시계열 데이터로 정제한다.

### 주요 처리 내용

1. 동일한 굴뚝, 동일한 측정 항목, 동일한 30분 슬롯을 기준으로 데이터를 그룹화한다.
2. 유효한 측정값 2개가 확보된 경우 평균을 계산한다.
3. 상태코드, 측정 단위 및 기준치의 유효성을 검증한다.
4. 정상적인 측정값은 정제된 관측값으로 활용하고, 비정상·결측·불량 데이터는 제외하거나 사유를 보존한다.
5. 기준 대비 비율인 `ratio_pct`를 계산한다.

현재 구현은 15분 원본 데이터를 동일한 굴뚝과 항목에 해당하는 30분 슬롯으로 구성하고, 유효한 값 2개가 있는 경우 평균을 계산하여 `ratio_pct`를 생성하는 구조다.

**핵심: 30분 단위로 정규화된 시계열 데이터 확보**

---

## 2. ML-ready: 모델 학습용 Feature 및 Label 생성

ML-ready 단계에서는 Silver의 정제된 시계열 데이터를 기반으로 머신러닝 학습에 필요한 Feature와 Label을 생성한다.

### 주요 처리 내용

1. 과거 측정값을 활용해 Lag Feature를 생성한다.
2. 최근 3시간의 평균과 표준편차를 계산하여 시계열 특성을 반영한다.
3. 시간, 월, 요일 정보를 Sin/Cos 형태로 변환하여 주기적인 패턴을 표현한다.
4. 60분 뒤의 실제 비율과 진입 여부를 Label로 생성한다.
5. Feature와 Label의 유효성을 구분하여 학습에 사용할 데이터를 결정한다.

예측 시점 이후의 정보가 입력 Feature에 포함되지 않도록 데이터 누수를 방지하는 것이 중요하다.

**핵심: 미래 정보 누수를 방지하면서 모델 학습에 필요한 Feature와 Label 구성**

---

## 3. 검토 및 보완이 필요한 사항

### ① 15분 → 30분 집계 기준

- 15분 측정값 2개가 모두 유효하지 않은 경우 어떻게 처리하는가?
- 두 값 중 한 개만 유효한 경우에도 평균을 계산하는가, 아니면 해당 30분 구간을 제외하는가?
- 집계 대상이 되는 15분 데이터의 시간 간격과 중복 여부도 확인하는가?

### ② 기준치 적용 방식

- `standard_value`는 30분 집계 구간에 어떤 기준으로 적용하는가?
- 기준치가 변경되면 변경 전후 데이터를 어떻게 구분하는가?
- 기준치 변경 시점이 30분 집계 구간 중간에 포함되는 경우 어떤 기준을 적용하는가?

### ③ 결측 및 품질 정보 관리

- Silver에서 제외한 데이터의 사유와 품질 정보가 별도로 보존되는가?
- 상태코드에 따른 제외 기준이 명확하게 정의되어 있는가?
- 제외된 데이터도 Bronze 원본을 통해 다시 확인할 수 있는가?

특히 Silver에서 비정상·결측 데이터를 제외하더라도 원본과 제외 사유를 추적할 수 있어야 한다.

### ④ 미래 예측 Label 생성 기준

- 60분 후 예측을 위해 Label을 생성할 때, 현재 시점 기준으로 정확히 60분 후의 측정값을 연결하고 있는가?
- 측정 데이터가 누락되거나 시간 간격이 일정하지 않은 경우에도 정확한 미래 시점을 찾아 Label을 생성하는가?
- 60분 후 실제 측정값이 결측인 경우 `label_valid`를 어떻게 처리하는가?

특히 30분 간격 데이터라는 이유만으로 단순히 다음 2개 행을 연결하면 안 된다. 실제 측정 시각을 기준으로 60분 후 데이터를 찾아야 하며, 해당 시점의 데이터가 없으면 Label을 유효하지 않은 것으로 처리하는 기준이 필요하다.

## 4. 최종 정리

| 단계 | 핵심 의미 | 주요 검토 사항 |
|---|---|---|
| Bronze | 원본 의미 보존 | 원본 데이터 및 추적 정보 유지 |
| Silver | 정제된 시계열 | 집계 기준, 기준치 적용, 결측 및 품질 관리 |
| ML-ready | 학습용 Feature/Label | 시계열 Feature 생성 및 미래 정보 누수 방지 |

## 5. 진행 방향

### ① 기준대비율 적용

- 한국과 대만의 측정 조건 및 배출허용기준을 확인한다.
- 산소보정, 건습 조건, 측정 단위 등의 비교 가능성을 검토한다.
- 비교 가능한 범위에서 기준대비율(ratio_pct)을 산출한다.

### ② 양국 데이터 통합

- 기준대비율을 공통 지표로 사용하여 한국 TMS와 대만 CEMS 데이터를 통합한다.
- 국가 구분 정보는 유지하여 데이터 출처를 추적할 수 있도록 한다.
- 원본 측정값과 적용된 허용기준도 함께 보존한다.

### ③ 통합 모델 구현

- 통합 데이터를 이용해 XGBoost 모델을 학습한다.
- 60분 후 기준대비율 예측을 목표로 한다.
- 예측 결과를 활용한 기준 초과 여부 판단도 검토한다.

### ④ 국내 데이터 기반 성능 검증

- 국내 Test 데이터를 이용하여 예측 성능을 평가한다.
- 회귀 예측은 MAE, RMSE 등을 활용한다.
- 국가별 측정 조건 및 시설 특성 차이에 따른 성능 저하 가능성을 확인하고 결과에 기록한다.

### ⑤ 프로젝트 범위 내 마무리

- 국가별 별도 모델까지 확장하지 않고 양국 통합 모델 구현에 집중한다.
- 국내 데이터에 대한 예측 성능과 적용 가능성을 확인한다.
- 통합 모델의 한계 및 추가 개선 사항은 결과 보고서에 정리한다.

## 6. 전체 데이터 처리 흐름

Bronze → Silver → ML-ready → Machine Learning Model

| 단계 | 핵심 역할 | 주요 처리 내용 |
|---|---|---|
| Bronze | 원본 데이터 보존 | 15분 원본 데이터 및 추적 정보 유지 |
| Silver | 정제된 시계열 생성 | 30분 집계, 기준치 적용, 결측·품질 관리, 기준대비율 계산 |
| ML-ready | 학습 데이터 생성 | 시계열 Feature 및 미래 Label 생성 |
| Machine Learning | 예측 모델 학습 | 양국 통합 데이터 기반 XGBoost 학습 및 국내 성능 평가 |

각 단계의 처리 기준을 명확히 정의하고 실제 데이터로 검증하는 것이 중요하다.

## 7. 최종 정리

이번 프로젝트에서는 다음 세 가지에 집중한다.

1. 데이터 정제 기준 확립: 15분에서 30분으로 집계하는 기준, 허용기준 적용 방식, 결측 및 품질 관리 기준을 명확히 한다.
2. 학습 데이터 품질 확보: 미래 정보 누수 없이 Feature와 Label을 생성하고, 정확히 60분 후의 측정값을 연결한다.
3. 양국 통합 모델 구현 및 검증: 기준대비율을 공통 지표로 활용해 한국과 대만 데이터를 통합하고, 국내 Test 데이터로 예측 성능을 확인한다.
