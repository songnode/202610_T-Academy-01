1. 임의의 가중치(`W`)를 선택합니다.
2. 그 `W` 지점에서 `loss function`의 그래프에 접하는 직선의 기울기를 구합니다. 즉, W에 대한 편미분을 수행하여 미분값을 구합니다.
3. 이렇게 구한 미분값에 `learning rate`라는 특정 파라미터 값을 곱한 후 현재 `W`에서 차감합니다.
4. 변경된 `W` 위치에서 반복적으로 미분을 수행하여 계산된 미분값이 작아지는 방향으로 `W`의 값을 반복적으로 감소(혹은 증가) 시킵니다.
5. 최종적으로는 미분값(접선의 기울기)이 더 이상 작아지지 않는 곳을 찾을 수 있는데 그 지점이 `loss function, E(W,b)`가 최소가 되는 W값 입니다.

이렇게 최소값을 찾아내는 알고리즘을 경사하강법(Gradient Descent)라고 해요.. 이런 류의 알고리즘들이 많이 존재하는데, 통칭해서 optimizer 라고 해요…

optimizer 중에 가장 기반이 되는 알고리즘은 경사하강법(Gradient Descent) 임.

# 5. 이상치와 정규화

머신러닝은 이론적인 부분(regression을 기반으로 다양한 알고리즘)을 이해하고 Tensorflow나 pytorch와 같은 라이브러리를 이용해서 구현하는 방식에 대해 알아가면 되요.

하지만 이렇게 구현을 한다해도 모델이 잘 안 만들어지는 경우가 많아요.!

가장 대표적인 이유는 데이터 전처리가 안되어 있어서 그래요!!!

내가 가지고 있는 데이터를 전처리해서 모델 구현에 적합하게 다듬는 것이 어려움.

데이터 전처리의 기본 3가지는

- 결측치 처리 : 비어있는 데이터 또는 NA 데이터 등..(값이 없는 경우)
    - 첫번째 방법은 삭제하는 거에요…!! 하지만, 이렇게 삭제하는 방법에는 약간의 문제가 생길 수 있어요.!
        
        머신러닝할 때 다양한 양질의 데이터가 많아야 됨…하지만, 데이터를 무조건 삭제하면 데이터 모수가 줄어듦. 따라서, 데이터 양이 줄어드는 것은 불안함.
        
        전체적인 데이터 량이 줄어드는 문제가 있어요.
        
        머신러닝에 사용하는 데이터(양질의 데이터)가 많으면 많을수록 좋아요.!!
        
        데이터 양의 일반적인 기준은 10만개가 있으면 괜찮다는 기준..(어느정도 머신러닝하기에 적합한 데이터이다…)
        
        만개 이하는 매우 부족하다..
        
        만 ~ 10만개 일 때는 좀 모자르지만 그래도 머신러닝을 해 볼만 하다…
        
        만약 데이터량이 충분히 많으면 결측치는 삭제하는게 가장 좋은 방식이에요!!!
        
    - 결측치를 다른 값으로 대치(데이터량이 적을 때) —> 데이터를 임의로 대체함 단, 데이터의 오염이 생길 수 있음.
        
        이 경우에는 데이터량의 감소는 피할 수 있지만, 데이터가 오염되요!!
        
- 이상치 처리 : 데이터가 이상한 경우..
    
    이상치는 값이 존재하기는 하는데 말 그대로 값이 이상한 경우에요.!!
    
    이런 값을 찾아서 삭제하거나 다른 값으로 대체할 필요가 있어요.!!!
    
    - 삭제 시, 데이터양이 줄어듦
    - 대체 시, 데이터가 오염됨(다른값으로 오염됨)
    
    이런 이상치를 판별하기 위한 여러가지 알고리즘이 있어요.
    
    - `Tukey’s Fence` : 4분위를 이용한 이상치 판별 알고리즘
    - `Z-score 를 이용한 방식` : 정규분포를 이용하는 방식

=⇒ 누가봐도 이상한 값인데, 그런데 실 데이터로 나올 수 있는 케이스가 있을 경우, 복잡해짐.

이런 경우에는 데이터를 삭제하면 안 됨. =⇒ 이럴 경우에는 도메인 전문가에게 이런 값이 실제 나올 수 있는 값인지 물어봐야 됨.

- 정규화(제일 중요함)
    
    머신러닝에 사용하는 데이터는 반드시 정규화가 진행되어야 해요!!! Normalization..
    
    정규화는 각 feature 의 scale 을 비슷하게 맞춰주는 작업을 지칭해요..!!
    

`데이터 전처리 과정`

`결측치 처리 → 이상치 처리 → 정규화 → 데이터의 bias(편향), in balence 을 잡아주는 작업이 필요함.`
