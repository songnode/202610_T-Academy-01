# RAG · CoT Prompting · LCEL 이해하기

## 1. 전체 개념 이해

LLM에게 질문하면 답변을 생성할 수 있지만, 사내 데이터나 최신 문서처럼 모델이 학습하지 않은 정보까지 정확하게 답변하기는 어렵습니다.

이를 보완하기 위해 RAG를 활용하고, 검색된 정보를 체계적으로 분석하도록 CoT Prompting을 적용하며, 각 기능을 하나의 흐름으로 연결하는 데 LCEL을 사용할 수 있습니다.

| 기술 | 핵심 역할 | 쉽게 이해하기 |
|---|---|---|
| RAG | 필요한 정보 검색 | 답변에 필요한 자료 찾기 |
| CoT Prompting | 분석 순서와 기준 제시 | 자료를 어떤 순서로 검토할지 안내 |
| LCEL | 기능 간 실행 흐름 연결 | 각각의 기능을 하나로 연결 |

전체 흐름은 다음과 같습니다.

```text
사용자 질문
    ↓
RAG : 관련 문서 검색
    ↓
CoT Prompting : 분석 방향과 기준 제시
    ↓
LLM : 검색된 정보를 바탕으로 답변 생성
    ↓
LCEL : 위 기능들을 하나의 파이프라인으로 실행
    ↓
최종 답변
```

※ LCEL은 별도의 AI 모델이나 분석 기법이 아니라, 각 기능을 연결하고 실행하는 프레임워크입니다.

## 2. RAG (Retrieval-Augmented Generation)

### RAG란?

RAG는 LLM이 답변을 생성하기 전에 외부 자료를 검색하고, 검색된 내용을 참고하여 답변하도록 하는 기술입니다.

쉽게 말하면 **LLM에게 필요한 참고 자료를 먼저 찾아주는 방식**입니다.

### RAG가 필요한 이유

일반적인 LLM은 학습한 지식을 기반으로 답변합니다.

하지만 다음과 같은 문제가 있습니다.

- 최신 정보가 반영되지 않을 수 있습니다.
- 사내 업무 문서나 내부 데이터는 알지 못합니다.
- 정확한 근거 없이 답변을 생성할 수 있습니다.

RAG는 이러한 문제를 줄이기 위해 외부 문서를 검색하여 LLM에 제공합니다.

### RAG 처리 과정

1. 문서 수집: PDF, Word, 데이터베이스 등에서 자료를 가져옵니다.
2. 문서 분할: 검색하기 좋은 작은 단위로 나눕니다.
3. 임베딩: 문서의 의미를 벡터로 변환합니다.
4. 검색: 사용자 질문과 관련된 문서를 찾습니다.
5. 답변 생성: 검색된 문서를 LLM에 전달하여 답변을 생성합니다.

**핵심:** RAG는 LLM이 답변할 때 참고할 수 있는 정보를 제공하는 기술입니다.

## 3. CoT Prompting (Chain of Thought)

### CoT란?

CoT는 LLM이 복잡한 질문에 답할 때 필요한 분석 단계를 순서대로 수행하도록 유도하는 프롬프트 기법입니다.

쉽게 말하면 **답부터 요구하는 것이 아니라, 어떤 기준으로 분석하고 결론을 내릴지 알려주는 방법**입니다.

### 일반 프롬프트와 CoT 비교

질문: 여러 문서를 종합하여 서울의 관광 환경을 설명해 주세요.

| 구분 | 프롬프트 방식 |
|---|---|
| 일반 프롬프트 | 서울의 관광 환경을 설명해 주세요. |
| CoT Prompting | ① 문서별 핵심 정보를 확인하세요. ② 공통점과 차이점을 비교하세요. ③ 정보 간 관계를 분석하세요. ④ 근거를 바탕으로 결론을 작성하세요. |

CoT를 적용하면 단순히 답변을 생성하는 것보다 복잡한 정보를 단계적으로 정리하도록 유도할 수 있습니다.

### 난이도별 프롬프트 전략

| 난이도 | 분석 수준 | 프롬프트 방향 |
|---|---|---|
| Easy | 단일 정보 확인 | 필요한 정보 찾기 |
| Medium | 여러 정보 통합 | 비교하고 정리하기 |
| Hard | 복합적인 정보 분석 | 관계 분석 후 결론 도출 |

**주의할 점:** CoT 프롬프트를 사용한다고 항상 정답률이 높아지는 것은 아닙니다. 분석 단계가 잘못되거나 근거가 부족하면 잘못된 결론을 내릴 수도 있습니다. 따라서 제공된 자료에 근거하도록 하고, 결과를 검증하는 과정이 필요합니다.

또한 실제 서비스에서는 모델의 내부 사고 과정을 그대로 노출하기보다 분석 근거와 요약, 최종 결론을 명확하게 제시하도록 설계하는 것이 좋습니다.

**핵심:** CoT는 LLM이 정보를 어떤 순서와 기준으로 분석할지 안내하는 방법입니다.

## 4. LCEL (LangChain Expression Language)

### LCEL이란?

LCEL은 LangChain에서 여러 기능을 연결하여 하나의 실행 파이프라인을 구성할 수 있도록 제공하는 표현 방식입니다.

쉽게 말하면 **검색, 프롬프트, LLM, 결과 변환 기능을 하나의 작업 흐름으로 연결하는 방법**입니다.

### LCEL이 필요한 이유

RAG 서비스를 만들려면 여러 기능이 필요합니다.

- 질문을 입력받는 기능
- 관련 문서를 검색하는 기능
- 검색 결과를 프롬프트에 전달하는 기능
- LLM을 호출하는 기능
- 최종 답변을 정리하는 기능

이 기능들을 각각 따로 실행하고 관리하면 코드가 복잡해질 수 있습니다.

LCEL을 사용하면 각 기능을 연결하여 하나의 파이프라인으로 구성할 수 있습니다.

### LCEL의 기본 구조

```text
Retriever → Prompt → LLM → Output Parser
```

| 구성 요소 | 역할 |
|---|---|
| Retriever | 질문과 관련된 문서 검색 |
| Prompt | 검색 결과와 질문을 LLM 입력 형태로 구성 |
| LLM | 입력된 내용을 분석하고 답변 생성 |
| Output Parser | 모델의 응답을 원하는 형태로 변환 |

LCEL에서는 `|` 연산자를 사용하여 기능을 연결합니다.

```python
chain = retriever | prompt | llm | output_parser
```

위 코드는 다음 순서로 동작합니다.

1. Retriever가 관련 문서를 검색합니다.
2. Prompt가 질문과 검색 결과를 결합합니다.
3. LLM이 답변을 생성합니다.
4. Output Parser가 최종 결과를 정리합니다.

※ 위 코드는 구조를 이해하기 위한 개념 예시입니다.

### LCEL의 주요 특징

- **연결성:** 서로 다른 기능을 하나의 파이프라인으로 연결합니다.
- **재사용성:** 만들어 놓은 기능을 다른 파이프라인에서도 활용할 수 있습니다.
- **확장성:** 검색, 모델, 출력 처리 기능을 필요에 따라 교체할 수 있습니다.
- **실행 관리:** 동기·비동기 실행 및 스트리밍 등 다양한 실행 방식을 지원합니다.

**핵심:** LCEL은 AI 기능들을 연결하고 관리하기 위한 실행 구조입니다.

## 5. 세 가지 기술의 관계

세 기술은 서로 대체하는 관계가 아니라 역할이 다릅니다.

| 구분 | RAG | CoT Prompting | LCEL |
|---|---|---|---|
| 해결하려는 문제 | 필요한 정보가 부족함 | 복잡한 분석이 필요함 | 기능 간 연결이 복잡함 |
| 주요 역할 | 정보 검색 | 분석 방향 제시 | 실행 흐름 구성 |
| 적용 위치 | 데이터 검색 단계 | 프롬프트 설계 단계 | 전체 파이프라인 |

### 실제 서비스 적용 예시

질문: "최근 3개월간 NOx 배출량이 증가한 사업장을 찾아 원인을 분석해 주세요."

```text
① 사용자 질문
   "NOx 배출량이 증가한 사업장은?"

② RAG
   관련 사업장 데이터와 분석 자료 검색

③ CoT Prompting
   - 기간별 배출량 비교
   - 증가 추세 확인
   - 관련 요인 검토
   - 근거를 바탕으로 분석 결과 정리

④ LLM
   검색된 자료를 바탕으로 분석 결과 생성

⑤ LCEL
   검색부터 답변 생성까지의 기능을 연결하고 실행
```

실제 TMS 서비스에서는 배출량 집계와 이상 여부 판정은 SQL이나 Python 등 검증 가능한 로직이 담당하고, LLM은 분석 결과의 요약과 설명을 담당하도록 역할을 분리하는 것이 바람직합니다.

## 6. 최종 정리

| 기술 | 기억해야 할 한 문장 |
|---|---|
| RAG | LLM에게 필요한 자료를 찾아준다. |
| CoT Prompting | LLM에게 분석 순서와 기준을 알려준다. |
| LCEL | 검색부터 답변까지의 기능을 연결한다. |

**강의 핵심 메시지**

RAG는 답변에 필요한 정보를 준비하고, CoT Prompting은 정보를 분석하는 방향을 제시하며, LCEL은 이러한 기능들이 하나의 흐름으로 동작하도록 연결합니다.

세 가지 기술을 함께 이해하면 단순히 LLM에 질문하는 수준을 넘어, 외부 데이터를 활용하고 복잡한 업무를 처리하는 AI 애플리케이션의 기본 구조를 이해할 수 있습니다.
