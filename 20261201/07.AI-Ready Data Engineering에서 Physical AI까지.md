# AI-Ready Data Engineering에서 Physical AI까지
## 산업용 멀티모달 AI 및 자율 지능형 시스템으로의 발전 방향

---

## 1. 개요

최근 AI 기술은 단순히 데이터를 분석하고 결과를 예측하는 수준에서 벗어나고 있습니다.

과거에는 AI가 데이터를 입력받아 분석 결과를 제공하는 것이 주요 역할이었다면, 최근에는 이미지, 영상, 센서, 텍스트 등 다양한 데이터를 종합적으로 이해하고, 상황에 맞는 행동까지 결정하는 방향으로 발전하고 있습니다.

이러한 발전 과정에서 중요한 기술이 다음과 같습니다.

- **AI-Ready Data Engineering**: AI가 학습하고 분석할 수 있는 데이터 기반 구축
- **Multimodal AI**: 서로 다른 형태의 데이터를 통합적으로 이해하는 AI
- **World Model**: 환경의 상태와 변화를 이해하고 예측하는 모델
- **VLA (Vision-Language-Action)**: 시각 및 언어 정보를 바탕으로 행동을 결정하는 모델
- **Embodied AI**: 가상 또는 실제 환경과 상호작용하는 AI
- **Physical AI**: 실제 물리적 환경에서 인식하고 판단하며 행동하는 AI

이번 TMS 프로젝트도 이러한 발전 방향과 연결할 수 있습니다.

현재는 산업 현장의 센서 및 영상 데이터를 활용하여 이상 징후를 탐지하고 사전에 경고하는 시스템을 구현하고 있지만, 향후에는 다양한 데이터를 종합적으로 이해하고 자율적인 점검 및 대응까지 수행하는 산업용 Physical AI로 확장할 수 있습니다.

> 핵심은 AI가 데이터를 분석하는 수준에서 벗어나, 주변 환경을 이해하고 상황에 맞는 행동까지 수행할 수 있도록 발전하는 것입니다.

## 2. AI 기술의 발전 흐름

AI 기술의 발전 방향을 이해하기 위해 다음 6가지 단계를 살펴보겠습니다.

| 단계 | 기술 | 핵심 역할 |
|---|---|---|
| 1 | AI-Ready Data Engineering | AI가 활용할 수 있는 데이터 구축 |
| 2 | Multimodal AI | 다양한 형태의 데이터 통합 및 이해 |
| 3 | World Model | 환경의 상태와 변화 예측 |
| 4 | VLA | 시각 및 언어 정보를 바탕으로 행동 결정 |
| 5 | Embodied AI | 환경과 상호작용하며 행동 수행 |
| 6 | Physical AI | 실제 물리적 환경에서 자율적으로 인식·판단·행동 |

### 전체 발전 구조

```text
       [AI-Ready Data Engineering]
                    |
                    v
             [Multimodal AI]
                    |
                    v
              [World Model]
                    |
                    v
                  [VLA]
                    |
                    v
              [Embodied AI]
                    |
                    v
              [Physical AI]
```

위 구조는 기술을 이해하기 위한 개념적인 발전 로드맵입니다.

실제 산업에서는 각 기술이 반드시 순차적으로 개발되는 것은 아니며, 서로 결합되어 동시에 발전하기도 합니다.

# 3. 1단계. AI-Ready Data Engineering

## AI가 제대로 학습하고 판단할 수 있도록 데이터를 준비하는 단계

### 3-1. AI-Ready Data란?

AI-Ready Data는 AI 모델이 학습하거나 추론할 수 있도록 수집, 정제, 표준화 및 구조화된 데이터를 의미합니다.

단순히 데이터를 저장하는 것과는 차이가 있습니다.

예를 들어 센서 데이터가 수집되었다고 해서 바로 AI 학습에 활용할 수 있는 것은 아닙니다.

- 결측치가 존재할 수 있습니다.
- 데이터 형식이 서로 다를 수 있습니다.
- 측정 시점이 일치하지 않을 수 있습니다.
- 이상값이나 잘못된 데이터가 포함될 수 있습니다.
- AI 학습에 필요한 정답 데이터가 없을 수 있습니다.

따라서 AI 모델을 개발하기 전에 데이터를 제대로 준비하는 과정이 필요합니다.

### 3-2. 주요 데이터 엔지니어링 작업

| 작업 | 설명 |
|---|---|
| Data Ingestion | 원천 데이터 수집 |
| Data Cleaning | 결측치 및 이상값 처리 |
| Data Transformation | 데이터 형식 및 구조 변환 |
| Data Standardization | 데이터 단위와 기준 통일 |
| Data Integration | 여러 데이터 소스 통합 |
| Feature Engineering | AI 학습에 필요한 특징 생성 |
| Data Quality | 데이터 품질 검증 |
| Data Versioning | 데이터 변경 이력 관리 |

### 3-3. TMS 프로젝트 적용

현재 TMS 프로젝트에서는 다음과 같은 데이터를 활용합니다.

| 데이터 | 출처 | 주요 내용 |
|---|---|---|
| 센서 데이터 | 대만 CEMS | NOx, SO2 농도 |
| 영상 데이터 | Project RISE | 산업 현장 및 굴뚝 영상 |
| 분석 데이터 | AI 모델 | 농도 예측, 연기 감지 및 분할 |
| 운영 데이터 | 시스템 | 경보 및 점검 이력 |

주요 기술:

- Kafka: 데이터 이벤트 수집 및 전달
- Airflow: 데이터 파이프라인 스케줄링
- Spark: 대용량 데이터 처리
- Iceberg: 데이터 레이크 테이블 관리
- S3 / MinIO: 데이터 저장

### 3-4. 데이터 레이크 구조

```text
          [원천 데이터]
                |
                v
          [Bronze Layer]
           원본 데이터
                |
                v
          [Silver Layer]
         정제 및 표준화
                |
                v
           [Gold Layer]
        AI 학습 및 분석 데이터
                |
                v
            [AI Model]
```

| 레이어 | 역할 | TMS 적용 |
|---|---|---|
| Bronze | 원본 데이터 저장 | CEMS 원본, RISE 영상 |
| Silver | 데이터 정제 및 표준화 | 정제된 센서 데이터, 영상 분석 결과 |
| Gold | AI 활용 데이터 | 모델 입력 데이터, 예측 결과, 통합 분석 데이터 |

**TMS 현재 구현 목표:** AI가 활용할 수 있는 데이터 플랫폼을 구축하고, 센서 및 영상 데이터를 안정적으로 수집·처리하는 것입니다.

# 4. 2단계. Multimodal AI (멀티모달 AI)

## 여러 종류의 데이터를 함께 이해하는 AI

### 4-1. 멀티모달 AI란?

Multimodal AI는 서로 다른 형태의 데이터를 함께 활용하여 상황을 이해하고 판단하는 AI 기술입니다.

여기서 Modality는 데이터의 형태 또는 정보의 유형을 의미합니다.

대표적인 데이터 유형은 다음과 같습니다.

| 데이터 유형 | 설명 | 예시 |
|---|---|---|
| Text | 텍스트 데이터 | 운영자 점검 기록 |
| Image | 이미지 데이터 | 굴뚝 연기 이미지 |
| Video | 영상 데이터 | 산업 현장 CCTV |
| Sensor | 센서 데이터 | NOx, SO2, 온도 |
| Audio | 음성 데이터 | 설비 작동 소음 |
| Spatial | 공간 데이터 | 위치 및 3D 정보 |

기존 AI가 하나의 데이터 유형을 중심으로 분석했다면, 멀티모달 AI는 여러 데이터의 관계를 함께 분석합니다.

### 4-2. TMS 적용 예시

예를 들어 굴뚝에서 연기가 발생하는 상황을 생각해 보겠습니다.

기존 방식은 센서 데이터만 분석하거나 영상만 분석합니다.

멀티모달 방식에서는 두 가지 분석 결과를 함께 활용합니다.

| 분석 항목 | 결과 |
|---|---|
| NOx | 농도 상승 |
| SO2 | 농도 변화 |
| 영상 분석 | 연기 영역 감지 |
| 연기 비율 | 증가 |
| 종합 분석 | 복합적인 이상 징후 발생 가능성 |

이렇게 하면 AI가 센서 수치뿐 아니라 영상에서 확인되는 상황까지 고려할 수 있습니다.

### 4-3. TMS 적용 기술

| 기술 | 역할 |
|---|---|
| YOLO | 영상 내 객체 탐지 |
| U-Net | 연기 영역 Segmentation |
| LSTM | 센서 시계열 예측 |
| XGBoost | 센서 데이터 기반 예측 |
| OpenCV | 영상 프레임 처리 |

**TMS 현재 구현 목표:** 센서 데이터와 영상 데이터를 개별적으로 분석하고, 분석 결과를 시간 및 설비 기준으로 연결하여 복합적인 상황을 이해할 수 있도록 하는 것입니다.

# 5. 3단계. World Model (월드 모델)

## AI가 현재 환경뿐 아니라 미래의 변화까지 이해하는 단계

### 5-1. World Model이란?

World Model은 AI가 주변 환경의 상태와 변화를 모델링하고, 특정 상황이나 행동에 따라 앞으로 어떤 일이 발생할지 예측하는 기술입니다.

쉽게 말하면 AI가 현재 상황만 이해하는 것이 아니라 미래에 어떤 변화가 발생할 수 있는지 내부적으로 예측하는 것입니다.

예를 들어 다음과 같은 질문을 생각할 수 있습니다.

- 현재 NOx 농도는 얼마인가?
- 앞으로 30분 후 NOx 농도는 어떻게 변할 것인가?
- 연기 영역이 시간에 따라 어떻게 확산되는가?
- 특정 행동을 수행하면 환경이 어떻게 변할 것인가?

일반적인 예측 모델은 미래의 특정 값을 예측하는 데 집중합니다.

반면 World Model은 환경의 상태와 시간에 따른 변화, 행동에 따른 결과까지 모델링하는 방향으로 확장됩니다.

### 5-2. TMS 적용 예시

| 분석 대상 | 예측 및 시뮬레이션 |
|---|---|
| NOx | 미래 농도 변화 |
| SO2 | 미래 농도 변화 |
| 연기 | 시간에 따른 연기 영역 변화 |
| 설비 상태 | 이상 상태로 발전할 가능성 |
| 대응 행동 | 특정 조치 이후 예상되는 변화 |

예를 들어 NOx 농도가 지속적으로 상승하는 상황에서 AI가 다음과 같이 판단하는 것을 생각할 수 있습니다.

```text
현재 NOx 농도 상승
        |
        v
미래 농도 변화 예측
        |
        v
30분 후 기준 초과 가능성 분석
        |
        v
위험 상황 발생 가능성 판단
```

### 5-3. 주요 기술

- 시계열 예측 모델
- 상태 공간 모델(State Space Model)
- 물리 기반 시뮬레이션
- 디지털 트윈(Digital Twin)
- 환경 변화 예측 모델

**TMS 향후 확장 목표:** 센서 및 영상 데이터의 시간적 변화를 모델링하고, 미래의 산업 현장 상태와 대응 결과를 예측하는 방향으로 발전시키는 것입니다.

※ 현재 TMS에서 사용하는 LSTM이나 XGBoost가 곧바로 World Model이 되는 것은 아닙니다. World Model로 발전하려면 환경 상태와 행동에 따른 결과까지 모델링하는 기능이 추가되어야 합니다.

# 6. 4단계. VLA (Vision-Language-Action)

## AI가 보고, 이해하고, 행동을 결정하는 단계

### 6-1. VLA란?

VLA는 Vision, Language, Action의 약자입니다.

시각 정보와 자연어 정보를 이해하고, 이를 바탕으로 필요한 행동을 결정하는 AI 기술입니다.

| 구성 요소 | 의미 | 역할 |
|---|---|---|
| Vision | 시각 | 영상 및 이미지 인식 |
| Language | 언어 | 자연어 이해 및 지시 해석 |
| Action | 행동 | 실제 수행할 행동 결정 |

예를 들어 산업 현장에서 연기가 감지되는 상황을 생각해 보겠습니다.

1. Vision: 카메라 영상에서 연기를 감지합니다.
2. Language: 현재 상황을 "굴뚝에서 연기가 확산되고 있다"고 이해합니다.
3. Action: 추가 관측 또는 현장 점검을 결정합니다.

### 6-2. TMS 적용 예시

TMS에서 VLA와 유사한 데이터 구조를 설계할 수 있습니다.

| 구성 | TMS 적용 데이터 |
|---|---|
| Observation | NOx, SO2, 연기 위치, 연기 비율 |
| Language | "연기 감지 및 NOx 농도 상승" |
| Action | 경보 발생, 점검 요청 |
| Feedback | 운영자 확인 및 점검 결과 |

### 6-3. VLA형 Episode 데이터

하나의 상황을 관측부터 행동 및 결과까지 연결하여 관리하는 구조입니다.

```json
{
  "episode_id": "EP_000001",
  "equipment_id": "STACK_001",
  "observation": {
    "nox": 93,
    "so2": 31,
    "smoke_detected": true
  },
  "language": {
    "description": "연기가 감지되었으며 NOx 농도가 상승하고 있음"
  },
  "action": {
    "type": "ALERT",
    "level": "WARNING"
  },
  "feedback": {
    "operator_confirmed": true,
    "inspection_result": "REQUIRES_INSPECTION"
  }
}
```

### 6-4. 가상 PTZ를 활용한 심화 실습

TMS 프로젝트에서는 실제 카메라 하드웨어 없이 가상 PTZ 카메라를 구현하는 방법도 있습니다.

PTZ는 다음 세 가지 기능을 의미합니다.

- Pan: 좌우 이동
- Tilt: 상하 이동
- Zoom: 확대 및 축소

구현 흐름:

```text
       [원본 영상]
            |
            v
     [U-Net Segmentation]
            |
            v
       [연기 영역 추출]
            |
            v
       [연기 중심 계산]
            |
            v
       [가상 PTZ Action]
            |
            v
      [Crop 영역 이동]
            |
            v
       [새로운 영상]
```

연기 영역의 중심이 화면 중앙에 오도록 이동량을 계산하여 가상 카메라의 행동 데이터를 생성합니다.

이렇게 만들어진 Observation-Action 데이터를 활용하면 Behavior Cloning(행동 모방 학습)도 실습할 수 있습니다.

**TMS 현재 및 심화 목표:** VLA형 데이터 구조를 설계하고, 심화 과제로 가상 PTZ를 활용한 행동 데이터 생성까지 시도하는 것입니다.

※ 경보 및 점검 요청을 생성하는 현재 TMS의 기능은 운영 의사결정 자동화입니다. 실제 로봇 행동을 학습하는 VLA와는 구분해야 합니다.

# 7. 5단계. Embodied AI (체화 AI)

## AI가 가상 또는 실제 환경과 상호작용하는 단계

### 7-1. Embodied AI란?

Embodied AI는 AI가 단순히 정보를 분석하는 데 그치지 않고, 환경과 상호작용하면서 인식하고 행동하는 기술입니다.

여기서 Embodied는 '몸을 가진' 또는 '환경에 체화된'이라는 의미입니다.

일반적인 AI는 화면 속 데이터를 분석하고 결과를 출력합니다.

반면 Embodied AI는 카메라, 로봇, 센서 등과 연결되어 주변 환경을 관측하고 행동하며 그 결과를 다시 반영합니다.

### 7-2. TMS 적용 예시

| 적용 대상 | 역할 |
|---|---|
| 가상 PTZ | 연기 위치에 따라 관측 영역 변경 |
| 영상 시뮬레이터 | 가상 환경에서 관측 및 행동 검증 |
| 드론 | 산업 현장 영상 수집 |
| 순찰 로봇 | 설비 상태 점검 |
| 로봇 카메라 | 관심 영역 능동적 관측 |

현재 TMS에서 검토한 가상 PTZ가 Embodied AI로 발전하기 위한 기초적인 실습 사례가 될 수 있습니다.

가상 PTZ는 실제 물리적인 움직임은 없지만, AI의 행동에 따라 관측 영역이 달라진다는 점에서 Active Perception(능동 인식)을 연습할 수 있습니다.

**향후 확장 목표:** 가상 환경에서 관측과 행동을 연결하고, 장기적으로 실제 로봇이나 드론과 연계하는 것입니다.

# 8. 6단계. Physical AI (피지컬 AI)

## 실제 물리적 환경에서 인식하고 판단하며 행동하는 AI

### 8-1. Physical AI란?

Physical AI는 AI가 실제 물리적 환경에서 주변 상황을 인식하고, 판단하고, 물리적인 행동을 수행하는 기술입니다.

대표적인 적용 분야는 다음과 같습니다.

| 분야 | 적용 사례 |
|---|---|
| 제조 | 산업용 로봇 및 자율 생산 |
| 물류 | 자율 이동 로봇(AMR) |
| 건설 | 자율 작업 장비 |
| 산업 안전 | 위험 구역 순찰 로봇 |
| 환경 관리 | 드론 기반 환경 모니터링 |
| 설비 관리 | 자율 설비 점검 로봇 |

### 8-2. TMS의 Physical AI 발전 방향

장기적으로 TMS를 다음과 같은 시스템으로 발전시킬 수 있습니다.

```text
       [산업 현장]
            |
            v
      [센서 및 카메라]
            |
            v
       [AI 환경 인식]
            |
            v
       [상황 및 위험 판단]
            |
            v
        [행동 계획]
            |
            v
    [드론 / 순찰 로봇]
            |
            v
        [현장 점검]
            |
            v
        [결과 수집]
            |
            v
       [AI 학습 및 개선]
```

예를 들어 AI가 특정 굴뚝에서 이상 징후를 발견하면 다음과 같은 과정으로 발전할 수 있습니다.

1. 센서와 영상 데이터를 통해 이상 징후를 감지합니다.
2. AI가 위험 상황을 판단합니다.
3. 추가 현장 점검이 필요하다고 결정합니다.
4. 드론이나 순찰 로봇에 점검 임무를 전달합니다.
5. 드론이나 로봇이 현장 정보를 수집합니다.
6. 수집된 데이터를 다시 AI 분석에 활용합니다.

다만 실제 설비 제어나 자율 로봇 운영에는 별도의 제어 시스템, 안전 장치, 시뮬레이션 및 운영자 승인 체계가 필요합니다.

**향후 발전 목표:** AI가 산업 현장을 스스로 관측하고, 위험 상황에 대응하며, 현장 점검까지 수행할 수 있는 지능형 산업 시스템으로 발전시키는 것입니다.

# 11. 멘티들이 반드시 이해해야 할 핵심 내용

이번 프로젝트의 핵심은 단순히 AI 모델을 개발하는 것이 아닙니다.

AI가 제대로 학습하고 판단하기 위해서는 먼저 데이터가 준비되어야 합니다.

그리고 다양한 데이터가 연결되면 AI는 하나의 데이터만 분석하는 것이 아니라 여러 정보를 종합적으로 이해할 수 있습니다.

이러한 기반 위에서 환경의 변화를 예측하고, 필요한 행동을 결정하며, 궁극적으로는 실제 물리적 환경과 상호작용하는 AI로 발전할 수 있습니다.

각 기술의 역할을 한 문장으로 정리하면 다음과 같습니다.

1. **AI-Ready Data Engineering:** AI가 활용할 수 있는 데이터를 만든다.
2. **Multimodal AI:** 다양한 데이터를 함께 이해한다.
3. **World Model:** 환경의 변화와 결과를 예측한다.
4. **VLA:** 상황을 이해하고 행동을 결정한다.
5. **Embodied AI:** 환경과 상호작용하며 행동한다.
6. **Physical AI:** 실제 물리적 환경에서 자율적으로 인식하고 판단하며 행동한다.

## 최종 정리

현재 TMS 프로젝트는 산업 현장의 센서 및 영상 데이터를 활용하여 이상 징후를 탐지하고 사전에 경고하는 AI 기반 시스템을 구축하는 프로젝트입니다.

이번 프로젝트에서 구축하는 AI-Ready Data Platform은 향후 멀티모달 AI, World Model, VLA 및 Physical AI로 발전하기 위한 중요한 기반이 될 수 있습니다.

**우리가 현재 구현하는 데이터 플랫폼은 단순히 데이터를 저장하는 시스템이 아니라, 미래의 AI가 산업 현장을 이해하고 판단하며 행동할 수 있도록 준비하는 기반 기술입니다.**

> **데이터를 수집하는 AI에서, 환경을 이해하는 AI로, 그리고 실제 환경에서 행동하는 AI로 발전하는 것이 앞으로의 중요한 기술 방향입니다.**
