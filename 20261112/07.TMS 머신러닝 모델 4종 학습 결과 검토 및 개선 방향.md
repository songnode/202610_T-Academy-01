# TMS 머신러닝 모델 4종 학습 결과 검토 및 개선 방향

- 검토일: 2026.11.12
- 대상 모델: N1-C, S1-C, N1-R, S1-R
- 목적: 4개 모델의 학습 결과를 이해하고, 현재 성능의 의미와 개선이 필요한 부분을 함께 검토한다.

---

## 1. 이번 검토에서 확인할 내용

이번 프로젝트에서는 NOx와 SO₂ 두 가지 배출 항목에 대해 분류 모델과 회귀 모델을 각각 학습했다.

이번 검토의 목적은 단순히 어떤 모델의 점수가 높은지 확인하는 것이 아니다.

다음 네 가지 질문에 답하는 것이 중요하다.

1. 모델이 실제 위험 상황을 얼마나 잘 찾아내는가?
2. 위험하지 않은 상황을 위험하다고 잘못 판단하는 경우는 얼마나 되는가?
3. 모델이 실제 운영 환경에서도 의미 있는 경고를 제공할 수 있는가?
4. 현재 모델의 한계를 개선하기 위해 어떤 데이터와 실험이 필요한가?

**가장 중요한 관점은 모델의 성능 점수와 실제 운영에 적합한 성능을 구분하는 것이다.**

## 2. 4개 모델의 역할 이해하기

먼저 각 모델이 무엇을 예측하는지 구분해야 한다.

| 모델 | 대상 물질 | 모델 유형 | 예측 목적 |
|---|---|---|---|
| N1-C | NOx | 분류(Classification) | 향후 60분 이내에 90% 이상으로 신규 진입할 위험이 있는지 판단 |
| S1-C | SO₂ | 분류(Classification) | 향후 60분 이내에 90% 이상으로 신규 진입할 위험이 있는지 판단 |
| N1-R | NOx | 회귀(Regression) | 정확히 60분 후의 배출 비율 예측 |
| S1-R | SO₂ | 회귀(Regression) | 정확히 60분 후의 배출 비율 예측 |

### 분류 모델과 회귀 모델의 차이

**분류 모델은 위험 여부를 판단한다.**

예를 들어 현재 배출 비율이 75%이고, 향후 60분 이내에 90% 이상으로 진입할 가능성이 있다고 판단하면 위험 경고를 발생시킨다.

**회귀 모델은 미래의 실제 수치를 예측한다.**

예를 들어 현재 배출 비율이 75%일 때, 60분 후의 배출 비율을 86%로 예측한다.

두 모델의 역할은 다르지만 운영 시스템에서는 서로 보완할 수 있다.

- 분류 모델: 위험 상황을 사전에 찾아내는 역할
- 회귀 모델: 미래 배출 비율을 예측하고 위험 수준을 판단하는 역할

현재 정본에서는 분류 모델의 예측 확률이 임계값 이상이거나, XGBoost 회귀 예측값이 90% 이상이면 경고하는 구조를 정의하고 있다. 따라서 두 모델을 따로 평가하는 것뿐 아니라 함께 사용했을 때의 효과도 확인해야 한다.

## 3. 모델별 학습 결과 비교

### 3.1 분류 모델: N1-C와 S1-C

분류 모델은 향후 60분 이내 위험 기준인 90%에 신규 진입할 가능성을 판단한다.

| 지표(Test) | N1-C (NOx) | S1-C (SO₂) |
|---|---:|---:|
| 실제 위험 비율 | 2.13% | 0.86% |
| Precision | 22.24% | 15.43% |
| Recall | 66.94% | 46.23% |
| F2 | 0.4774 | 0.3304 |
| AP | 0.3106 | 0.1611 |
| 경고 중 오경보 비율 | 77.76% | 84.57% |

※ S1-C의 Validation 혼동행렬은 원자료가 아니라 기존 지표를 바탕으로 역산한 값이 포함되어 있으므로, 최종 비교 시 원자료 확인이 필요하다.

### 주요 지표를 이해하기

| 지표 | 의미 | 쉽게 설명하면 |
|---|---|---|
| Precision(정밀도) | 위험하다고 예측한 것 중 실제 위험한 비율 | 경고가 얼마나 정확한가? |
| Recall(재현율) | 실제 위험한 것 중 모델이 찾아낸 비율 | 실제 위험을 얼마나 놓치지 않았는가? |
| F1 | Precision과 Recall의 조화평균 | 정확도와 탐지율을 균형 있게 평가 |
| F2 | Recall에 더 높은 가중치를 둔 지표 | 오경보보다 위험을 놓치지 않는 것을 더 중요하게 평가 |
| AP | 여러 임계값에서 Precision-Recall 관계를 종합한 지표 | 위험한 사례를 정상 사례보다 얼마나 잘 구분해 순위를 매기는가? |

AP는 특정 임계값 하나에서 계산하는 Precision이나 Recall과 다르다. 여러 임계값에 걸친 Precision-Recall 성능을 종합하므로, 분류 모델의 전반적인 선별 능력을 비교할 때 활용할 수 있다.

다만 AP가 높다고 실제 운영에서 오경보가 적다는 뜻은 아니다. 실제 운영 임계값에서 Precision과 Recall도 함께 확인해야 한다.

### N1-C 결과 해석

N1-C는 다음과 같은 특징을 보인다.

- 실제 위험 데이터의 약 66.94%를 찾아냈다.
- 위험하다고 발생시킨 경고 중 약 22.24%만 실제 위험이었다.
- 반대로 경고의 약 77.76%는 오경보였다.
- Accuracy는 94.31%이지만, 모든 데이터를 정상이라고 예측하는 기준선의 Accuracy는 97.87%다.

따라서 Accuracy만으로 모델이 우수하다고 판단하면 안 된다.

위험 데이터 자체가 전체의 2.13%에 불과하기 때문에 정상으로만 예측해도 높은 Accuracy가 나오기 때문이다.

**핵심은 N1-C가 위험을 어느 정도 찾아내고 있지만, 오경보가 많아 현재 임계값 그대로 운영하기에는 부담이 있다는 것이다.**

### S1-C 결과 해석

S1-C는 N1-C보다 Precision과 Recall이 낮다.

그렇다고 단순히 S1-C의 모델 품질이 더 나쁘다고 결론 내리면 안 된다.

SO₂의 실제 위험 비율은 0.86%로 NOx의 2.13%보다 훨씬 낮다. 위험 사례가 드물수록 오경보가 Precision에 미치는 영향이 커진다.

양성 비율 대비 AP를 참고하면 다음과 같다.

| 항목 | N1-C | S1-C |
|---|---:|---:|
| AP | 0.3106 | 0.1611 |
| 실제 위험 비율 | 2.13% | 0.86% |
| AP ÷ 위험 비율 | 약 14.6배 | 약 18.7배 |

이 배수는 실제 위험 비율을 고려한 참고 지표다. 정식 성능 평가 지표나 통계적 유의성을 의미하지는 않는다.

S1-C는 절대적인 Precision과 Recall은 낮지만, 위험 비율을 고려한 선별력은 확인할 수 있다.

다만 운영자 입장에서는 경고의 약 84.57%가 오경보라는 점이 중요한 문제다.

**분류 모델에서 기억할 점**

- AP는 모델이 위험 사례를 얼마나 잘 선별하는지 확인한다.
- Precision은 경고의 신뢰도를 보여준다.
- Recall은 실제 위험을 얼마나 놓치지 않는지 보여준다.
- F1과 F2는 운영 목적에 따라 임계값을 선택할 때 참고한다.

### 3.2 회귀 모델: N1-R과 S1-R

회귀 모델은 60분 후의 배출 비율을 숫자로 예측한다.

| 지표(Test) | N1-R (NOx) | S1-R (SO₂) |
|---|---:|---:|
| MAE | 4.2547 | 3.2406 |
| RMSE | 7.3464 | 7.5055 |
| RMSE ÷ MAE | 1.73 | 2.32 |

단위는 배출 비율의 %p이다.

### 회귀 모델 지표 이해하기

**MAE(Mean Absolute Error)**

실제값과 예측값의 차이를 절댓값으로 계산한 평균이다.

예를 들어 실제 배출 비율이 80%이고 예측값이 75%라면 오차는 5%p다.

MAE가 4.25라면 전체 평가 데이터에서 평균적으로 약 4.25%p 차이가 발생했다는 의미다.

**RMSE(Root Mean Squared Error)**

오차를 제곱한 뒤 평균을 구하고 다시 제곱근을 계산한다.

큰 오차에 더 큰 영향을 받기 때문에 MAE와 함께 확인하면 일부 구간에서 큰 예측 오류가 발생하는지 파악하는 데 도움이 된다.

### N1-R 결과 해석

- MAE는 약 4.25%p다.
- RMSE는 약 7.35%p다.
- RMSE가 MAE보다 상당히 크므로 일부 데이터에서 상대적으로 큰 예측 오차가 발생했을 가능성이 있다.

### S1-R 결과 해석

- MAE는 약 3.24%p로 N1-R보다 작다.
- RMSE는 약 7.51%p로 N1-R보다 크다.
- RMSE ÷ MAE가 2.32로 N1-R의 1.73보다 크다.

즉, S1-R은 평균 절대오차만 보면 좋아 보이지만, 일부 데이터에서는 큰 오차가 발생하는 특성이 있다.

다만 두 물질의 실제 배출 비율 분포가 다르므로 MAE 숫자만으로 어느 모델이 더 우수하다고 판단해서는 안 된다.

또한 RMSE ÷ MAE만으로 오차 분포의 원인을 확정할 수는 없다. 오차 상위 구간을 별도로 분석해야 한다.

**회귀 모델에서 가장 먼저 확인할 것은 Persistence 기준선이다.**

Persistence는 미래값을 별도로 학습해 예측하지 않고, 현재값이 60분 후에도 유지된다고 가정하는 단순 기준선이다.

예를 들어 현재 배출 비율이 75%라면 60분 후에도 75%라고 예측한다.

XGBoost가 이 단순한 방법보다 실제로 얼마나 개선되었는지 확인해야 회귀 모델의 학습 효과를 판단할 수 있다.

현재는 N1-R과 S1-R 모두 Persistence와 비교한 결과가 없으므로, 성능이 충분하다고 판단하기 어렵다.

## 4. 국내 TMS 데이터 적용 결과

대만 CEMS 데이터로 학습한 모델을 국내 CleanSYS TMS 데이터에 적용하는 것은 실제 프로젝트 목표를 고려할 때 중요한 검증이다.

현재 국내 평가 결과가 확인된 모델은 N1-C다.

| 항목 | 대만 Test | 국내 TMS |
|---|---:|---:|
| Precision | 22.24% | 16.8% |
| Recall | 66.94% | 46.6% |
| AP | 0.3106 | 0.1775 |
| 실제 위험 비율 | 2.13% | 약 0.43% |

국내 데이터는 실제 위험 비율이 대만보다 낮다.

따라서 AP와 Precision이 낮아진 사실만으로 모델의 일반화 성능이 크게 떨어졌다고 단정해서는 안 된다.

하지만 Recall이 약 66.9%에서 46.6%로 낮아졌다는 점은 주의해서 봐야 한다.

국내 환경에서는 평소 배출 비율이 낮은 상태에서 갑자기 상승하는 사례가 있으며, 이러한 상황을 모델이 충분히 탐지하지 못할 가능성이 있다.

N1-C 분석에서는 놓친 위험(FN)의 약 62%가 직전 1시간 동안 변화가 거의 없거나 감소하던 사례로 나타났다.

이는 과거 배출 비율과 변화량만으로는 미리 포착하기 어려운 급격한 상승 사례가 존재한다는 점을 보여준다.

다만 국내 평가 기간은 11일로 길지 않으므로, 현재 결과를 국내 전체 사업장의 일반화 성능으로 확대 해석해서는 안 된다.

**추가 확인이 필요한 내용**

- S1-C의 국내 평가
- N1-R과 S1-R의 국내 평가
- 국내 데이터에서 실제값 90% 이상인 구간의 회귀 오차
- 국내 데이터에서 위험을 놓치는 패턴이 대만과 동일한지 여부

## 5. 현재 학습 결과에서 확인된 주요 문제

이번 검토에서 중요한 점은 모델 자체의 성능뿐 아니라, 모델을 평가하고 관리하는 체계에도 보완할 부분이 있다는 것이다.

### 5.1 모델 결과를 재현할 수 있어야 한다

현재 N1-C는 실제 모델 파일로 Test 결과를 다시 계산해 기존 보고서와 일치하는 것을 확인했다.

반면 S1-C, N1-R, S1-R은 모델 파일과 학습 설정을 직접 확인한 근거가 부족하다.

모델 결과를 신뢰하려면 다음 정보가 연결되어야 한다.

- 모델 ID와 모델 파일
- 학습에 사용한 데이터와 데이터 버전
- Feature 목록과 생성 코드 버전
- 하이퍼파라미터 및 학습 설정
- random_state와 학습 실행 정보
- 평가 결과 파일

단순히 metrics.json 파일만 보관하는 것으로는 어떤 모델이 어떤 데이터로 학습되었는지 추적하기 어렵다.

### 5.2 공통 기준선이 필요하다

분류와 회귀는 서로 다른 기준선으로 평가해야 한다.

| 모델 유형 | 비교 기준선 | 확인 목적 |
|---|---|---|
| 분류 | Rule Engine | 기존 규칙보다 위험을 더 잘 찾아내는가? |
| 회귀 | Persistence | 현재값을 미래값으로 사용하는 것보다 정확한가? |

N1-C는 기존 규칙과 비교한 결과가 있다.

동일한 Recall을 기준으로 비교했을 때 모델의 경고 행 수가 기존 규칙보다 약 44% 감소했다.

이는 N1-C가 단순히 현재 비율만 확인하는 규칙보다 추가적인 선별 정보를 제공할 가능성을 보여주는 결과다.

반면 회귀 모델은 Persistence와 비교한 결과가 아직 없다.

따라서 회귀 모델은 MAE와 RMSE만으로 성능을 평가하지 말고, 기준선 대비 개선 정도를 반드시 확인해야 한다.

### 5.3 실제 운영 기준으로 평가해야 한다

현재 보고서에는 행 단위 성능 지표가 중심으로 들어가 있다.

하지만 운영 환경에서는 행 하나가 아니라 실제 위험 사건과 경고가 중요하다.

예를 들어 30분 간격 데이터에서 90% 이상인 행이 연속으로 4개 발생했다고 해서 경고 4건이 발생했다고 해석하는 것은 적절하지 않을 수 있다.

연속된 위험 구간을 하나의 사건으로 묶어 평가할 필요가 있다.

앞으로는 다음 항목을 추가해야 한다.

- 사건 단위 Recall: 실제 위험 사건 중 찾아낸 사건의 비율
- 사건 단위 Precision: 경고한 사건 중 실제 위험 사건의 비율
- 사건 단위 F1: 사건 기준의 정밀도와 재현율 균형
- Lead Time: 실제 위험 진입 전에 얼마나 일찍 경고했는지
- 하루·배출구당 오경보 건수
- 회귀 모델의 위험 구간 예측 오차

특히 Lead Time은 사전 경고 시스템에서 중요한 지표다.

위험 발생 직전에 경고하는 것과 60분 전에 경고하는 것은 운영상 가치가 다르기 때문이다.

### 5.4 한 번의 학습 결과만으로 판단하지 않는다

현재 4개 모델의 결과는 기본적으로 random_state 42의 단일 실행 결과다.

한 번의 실행 결과만으로는 학습 조건이나 데이터 샘플링에 따라 성능이 얼마나 달라지는지 알 수 없다.

따라서 다음과 같은 검증이 필요하다.

- random_state를 3~5개로 변경하여 반복 학습
- 반복 실행별 AP, Recall, MAE, RMSE 비교
- 배출구 단위 Bootstrap으로 신뢰 구간 산출
- 시간 순서를 유지한 교차 검증으로 기간별 성능 확인

이를 통해 V1.1에서 AP가 0.01 상승했을 때 실제 개선인지, 반복 실행에 따른 변동인지 판단할 수 있다.

## 6. 모델 4종을 함께 사용하는 방법 검토

현재 정본에서는 분류와 회귀를 함께 활용하는 구조를 정의하고 있다.

예를 들어 NOx의 경우 다음 두 조건 중 하나라도 만족하면 경고하는 방식이다.

1. N1-C 분류 예측 확률이 설정한 임계값 이상인 경우
2. N1-R 회귀 예측값이 90% 이상인 경우

이 방식은 분류 모델이 놓친 위험을 회귀 모델이 추가로 찾아낼 수 있다는 기대를 가지고 있다.

하지만 실제로 그런 효과가 있는지는 별도 검증이 필요하다.

| 확인할 내용 | 검토 목적 |
|---|---|
| 분류 모델만 사용했을 때 경고 건수 | 현재 기준 성능 확인 |
| 회귀 모델만 사용했을 때 경고 건수 | 회귀 모델의 단독 경고 성능 확인 |
| 분류 OR 회귀 결합 결과 | 결합했을 때 Recall이 얼마나 증가하는지 확인 |
| 추가 경고 건수 | Recall 개선을 위해 오경보가 얼마나 늘어나는지 확인 |
| 분류 모델의 FN 중 회귀가 탐지한 비율 | 두 모델이 서로 보완하는지 확인 |

특히 분류 모델이 놓친 위험을 회귀 모델이 얼마나 추가로 탐지하는지가 중요하다.

두 모델이 같은 입력 데이터를 사용하고 비슷한 패턴을 학습했다면 동일한 위험을 함께 놓칠 수도 있다.

따라서 단순히 두 모델의 성능을 각각 확인하는 것보다 **두 모델을 결합했을 때 실제로 추가적인 탐지 효과가 발생하는지** 검증해야 한다.

## 8. 멘토링에서 함께 이야기할 핵심 질문

교육생들이 결과를 단순히 보고하는 데서 끝나지 않고, 직접 분석하고 설명할 수 있도록 다음 질문을 중심으로 논의하면 좋겠다.

### 질문 1. 분류 모델의 Accuracy가 높으면 좋은 모델인가?

- N1-C의 Accuracy는 94.31%다.
- 모든 데이터를 정상으로 예측하는 기준선은 97.87%다.
- 왜 Accuracy만으로 모델을 평가하면 안 되는가?

**기대하는 설명:** 위험 데이터가 전체에서 차지하는 비율이 낮기 때문에 정상으로만 예측해도 높은 Accuracy가 나온다. 따라서 AP, Precision, Recall 등을 함께 확인해야 한다.

### 질문 2. AP가 높으면 실제 경고도 정확한가?

- AP는 여러 임계값에서 위험 데이터를 얼마나 잘 선별하는지 평가한다.
- 실제 운영 임계값에서는 N1-C도 경고의 약 78%가 오경보다.

**기대하는 설명:** AP는 모델의 전반적인 선별 능력을 보여주지만, 특정 임계값에서 발생하는 오경보와 미탐을 직접 설명하지는 않는다. 운영 임계값에서 Precision과 Recall을 함께 확인해야 한다.

### 질문 3. S1-R의 MAE가 N1-R보다 낮으면 더 좋은 모델인가?

- S1-R MAE: 3.24
- N1-R MAE: 4.25
- S1-R RMSE: 7.51
- N1-R RMSE: 7.35

**기대하는 설명:** 물질별 실제값 분포가 다르므로 MAE만으로 직접 비교할 수 없다. Persistence 기준선과 비교하고, 큰 오차가 발생하는 구간을 별도로 분석해야 한다.

### 질문 4. 회귀 모델을 분류 모델과 함께 사용하는 이유는 무엇인가?

- 분류 모델은 위험 여부를 판단한다.
- 회귀 모델은 미래 배출 비율을 예측한다.

**기대하는 설명:** 분류 모델이 놓친 위험을 회귀 모델이 추가로 찾아낼 수 있다. 다만 실제 결합 효과는 OR 조건을 적용한 결과로 검증해야 한다.

### 질문 5. 대만 데이터에서 성능이 좋으면 국내에서도 잘 작동하는가?

- N1-C Recall은 대만 Test에서 약 66.9%다.
- 국내 평가에서는 약 46.6%다.

**기대하는 설명:** 학습 데이터와 실제 적용 데이터의 배출 특성 및 분포가 다를 수 있다. 따라서 국내 데이터를 별도로 평가하고, 특히 낮은 배출 비율에서 급격하게 상승하는 위험을 얼마나 탐지하는지 확인해야 한다.

### 질문 6. 현재 모델을 운영에 적용해도 되는가?

**기대하는 설명:** 현재 결과만으로 운영 적용을 확정하기 어렵다. 오경보와 미탐, 사건 단위 성능, Lead Time, 기준선 대비 개선, 국내 일반화 성능 등을 확인한 뒤 운영 기준에 따라 판단해야 한다.

## 9. 최종 정리

이번 4개 모델의 학습 결과를 검토하면서 확인한 내용은 다음과 같다.

1. **분류 모델은 위험 사례를 선별하는 신호를 확인했다.** 다만 오경보 비율이 높아 현재 임계값을 그대로 운영에 적용하기는 어렵다.
2. **회귀 모델은 예측 오차를 확인했지만, 성능이 충분한지는 아직 판단하기 어렵다.** Persistence 기준선과 비교해야 한다.
3. **N1-C는 모델 파일 재현과 국내 평가, 사건 단위 분석까지 진행되어 다른 모델보다 근거가 구체적이다.** 나머지 모델도 동일한 방식으로 검증할 필요가 있다.
4. **모델별 평가 기준을 통일해야 한다.** 분류는 Rule Engine, 회귀는 Persistence를 기준으로 비교하고, 운영 지표까지 함께 확인해야 한다.
5. **분류와 회귀를 결합했을 때 실제로 위험 탐지 효과가 높아지는지 검증해야 한다.**
6. **한 번의 학습 결과만으로 모델의 성능을 확정하지 말고, 반복 학습과 시간 기반 교차 검증으로 안정성을 확인해야 한다.**

### 멘티들에게 전달할 핵심 메시지

모델을 학습하고 성능 지표를 산출하는 것도 중요하지만, 그 결과가 실제로 어떤 의미를 가지는지 설명할 수 있어야 합니다.

특히 이번 프로젝트에서는 단순히 AP, MAE, RMSE가 얼마인지 설명하는 수준을 넘어 다음 질문에 답할 수 있어야 합니다.

- 기존 방식보다 무엇이 좋아졌는가?
- 어떤 위험을 찾아내고, 어떤 위험을 놓치는가?
- 오경보는 어느 정도 발생하는가?
- 회귀 모델을 추가하면 실제로 어떤 효과가 있는가?
- 국내 TMS 환경에서도 동일한 성능을 기대할 수 있는가?

**최종적으로 중요한 것은 높은 성능 점수를 만드는 것이 아니라, 모델이 판단한 결과를 데이터와 실험 근거로 설명하고 실제 운영에 적용할 수 있는 수준인지 검증하는 것이다.**
