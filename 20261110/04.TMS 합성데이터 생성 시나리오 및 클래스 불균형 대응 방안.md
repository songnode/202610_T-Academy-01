# TMS 합성데이터 생성 시나리오 및 클래스 불균형 대응 방안

## 1. 합성데이터 생성 시 추가로 필요한 시나리오

현재 정의된 S-01~S-10 시나리오는 정상 상태, 임계치 접근, 급격한 상승, 완만한 상승, 재진입 및 데이터 품질 문제 등을 포함하고 있어 전반적으로 적절합니다.

다만, 실제 운영 환경에서 발생할 수 있는 다양한 패턴을 추가로 검증하기 위해 다음 3개 시나리오를 추가하는 것을 권장합니다.

### 1.1 추가 시나리오

| ID | 시나리오 | 생성 패턴 | 주요 검증 목적 |
|---|---|---|---|
| S-11 | 반복 진동 | 75~89% 구간에서 상승·하락 반복 | 임계치 부근의 반복 변동에 따른 불필요한 경보 억제 |
| S-12 | 급상승 후 유지 | 60% → 90% 진입 후 일정 시간 90% 이상 유지 | 임계치 초과 이후 지속 상태 확인 |
| S-13 | 급상승 후 급락 | 60% → 90% 진입 후 30분 이내 70% 수준으로 하락 | 일시적 초과와 지속적 초과 상황 구분 |

각 시나리오는 다음과 같은 목적을 가집니다.

- **S-11 반복 진동:** 임계치에 가까워졌다는 이유만으로 양성으로 판단하지 않도록 학습 데이터를 확보합니다.
- **S-12 급상승 후 유지:** 임계치에 진입한 이후에도 높은 배출비율이 지속되는 상황을 재현합니다.
- **S-13 급상승 후 급락:** 임계치에 진입했지만 이후 빠르게 정상 수준으로 돌아오는 상황을 재현합니다.

특히 S-11은 기존 S-06 Near-miss와 구분할 필요가 있습니다. S-06은 임계치에 접근한 후 하락하는 패턴이고, S-11은 임계치 부근에서 상승과 하락을 반복하는 패턴입니다.

### 1.2 60분 예측 Label 기준과 시나리오의 일치 여부

합성데이터를 생성할 때 가장 중요한 것은 시나리오 자체가 아니라, 생성된 측정값이 실제 분류 Label 기준과 일치하는지 확인하는 것입니다.

현재 프로젝트의 분류 Label은 다음과 같습니다.

- 현재 배출비율이 90% 미만인 경우만 분류 대상입니다.
- 현재 시점부터 30분 또는 60분 후 중 하나라도 90% 이상이면 `1`(양성)입니다.
- 30분 후와 60분 후가 모두 유효하고 90% 미만이면 `0`(음성)입니다.
- 현재 이미 90% 이상이거나 미래 판정이 불가능하면 `NULL`(분류 제외)입니다.

즉, 현재 시점의 배출비율이 90% 미만이어야 하며, 미래 두 시점 중 하나라도 90% 이상이면 양성으로 판단합니다. 정확히 90%인 경우도 양성에 포함합니다.

| 현재 시점 | T+30분 | T+60분 | Label | 판단 |
|---:|---:|---:|---:|---|
| 60% | 70% | 80% | 0 | 두 미래 시점 모두 90% 미만 |
| 80% | 89% | 90% | 1 | 60분 이내 90% 진입 |
| 85% | 90% | 92% | 1 | 30분 이내 90% 진입 |
| 88% | 89% | 91% | 1 | 60분 이내 90% 진입 |
| 92% | 95% | 97% | NULL | 현재 이미 90% 이상 |
| 80% | 결측 | 85% | NULL | 양성 조건은 없고 미래 판정 불가 |
| 80% | 85% | 결측 | NULL | 음성 판정에 필요한 미래 데이터 부족 |

단, T+30 또는 T+60 중 하나라도 90% 이상인 경우에는 다른 미래 측정값이 누락되어도 양성으로 판정할 수 있습니다.

**시나리오별로 Label을 직접 지정하지 말고, 생성된 측정값을 기준으로 Label을 자동 산출해야 합니다.**

예를 들어 S-05 서서히 상승 시나리오를 다음과 같이 생성했다고 가정하겠습니다.

| 시점 | 배출비율 | Label |
|---|---:|---:|
| T0 | 60% | 0 |
| T+30분 | 65% | 0 |
| T+60분 | 70% | 0 |
| T+90분 | 76% | 0 |
| T+120분 | 83% | 1 |
| T+150분 | 90% | 분류 제외 |

초기에는 상승 추세가 있더라도 60분 이내에 90%에 진입하지 않으므로 음성입니다. 반면 T+120분 시점에서는 60분 후 90%에 진입하므로 양성입니다.

이처럼 하나의 시나리오 안에서도 측정 시점에 따라 양성과 음성이 모두 발생할 수 있습니다.

따라서 합성데이터 생성 로직은 다음 순서로 구현하는 것이 좋습니다.

1. 시나리오별 측정값 생성
2. 굴뚝·물질별 30분 측정 시계열 구성
3. 현재 측정값과 T+30·T+60 측정값 확인
4. 위 Label 기준에 따라 `0`, `1`, `NULL` 자동 생성
5. 시나리오별 양성·음성·제외 건수 확인

이렇게 구현해야 합성데이터가 실제 학습 데이터와 동일한 Label 기준을 유지할 수 있습니다.

### 1.3 추가 시나리오 생성 시 주의사항

- S-11~S-13도 NOx와 SO₂의 상승 속도 및 변동 특성을 구분하여 생성합니다.
- 특정 패턴만 반복적으로 생성하지 않도록 상승 폭, 지속 시간, 하락 속도에 변화를 줍니다.
- 실제 데이터에서 관찰되는 변동 범위를 참고하여 합성데이터의 생성 범위를 설정합니다.
- 미래 측정값은 Label 생성에만 사용하고 모델 Feature에는 포함하지 않습니다.
- Label이 `NULL`인 데이터는 분류 학습 데이터에서 제외하되, 원본 수집 및 파이프라인 검증에는 활용할 수 있습니다.

## 2. 클래스 불균형 해소 관점에서 추가로 고려할 사항

현재 프로젝트의 대만 CEMS 데이터는 NOx와 SO₂의 양성 비율 차이가 크고, 전체적으로 양성 데이터가 부족한 상태입니다.

따라서 합성데이터를 생성할 때는 단순히 전체 데이터 건수를 늘리는 것이 아니라, 실제 데이터에서 부족한 양성 패턴을 보완하는 방향으로 생성해야 합니다.

### 2.1 현재 데이터의 클래스 불균형 현황

| 구분 | NOx | SO₂ | 전체 |
|---|---:|---:|---:|
| 분류 학습 가능 데이터 | 5,477,394 | 4,380,490 | 9,857,884 |
| 양성 데이터 | 106,931 | 26,785 | 133,716 |
| 음성 데이터 | 5,370,463 | 4,353,705 | 9,724,168 |
| 양성 비율 | 약 1.95% | 약 0.61% | 약 1.36% |

현재 전체 양성 비율은 약 1.36%이며, 음성과 양성의 비율은 약 73:1입니다.

특히 SO₂는 양성 비율이 약 0.61%로 NOx보다 더 낮기 때문에, 동일한 비율로 합성데이터를 생성하는 것은 적절하지 않습니다.

### 2.2 합성데이터 생성 시 60분 예측 Label 기준 적용

합성데이터로 양성 데이터를 보완할 때도 다음 Label 기준을 반드시 적용해야 합니다.

- 현재 배출비율이 90% 미만인 경우만 분류 대상입니다.
- 현재 시점부터 30분 또는 60분 후 중 하나라도 90% 이상이면 `1`입니다.
- 30분 후와 60분 후가 모두 유효하고 90% 미만이면 `0`입니다.
- 현재 이미 90% 이상이거나 미래 판정이 불가능하면 `NULL`입니다.

이 기준을 적용하지 않고 시나리오 ID만으로 양성·음성을 지정하면 실제 데이터와 합성데이터의 Label 생성 기준이 달라질 수 있습니다.

예를 들어 S-05 서서히 상승 시나리오에서 60%부터 90%까지 상승하는 데이터가 생성되더라도 모든 측정 시점을 양성으로 지정하면 안 됩니다.

현재 시점 기준으로 향후 60분 이내 90% 진입 여부를 판단해야 하므로, 초기 상승 구간은 음성일 수 있고 임계치 진입이 가까워진 시점부터 양성이 됩니다.

따라서 **합성데이터의 양성 건수는 시나리오 생성 건수가 아니라 Label 자동 생성 결과를 기준으로 집계해야 합니다.**

### 2.3 NOx와 SO₂별 합성데이터 생성 비율 분리

NOx와 SO₂는 현재 양성 비율이 다르므로 합성데이터 생성 파라미터도 별도로 관리하는 것을 권장합니다.

| 구분 | NOx | SO₂ |
|---|---|---|
| 현재 양성 비율 | 약 1.95% | 약 0.61% |
| 생성 규칙 | 별도 설정 | 별도 설정 |
| 상승 속도 | 별도 설정 | 별도 설정 |
| 임계치 진입 빈도 | 별도 설정 | 별도 설정 |
| 복귀 패턴 | 별도 설정 | 별도 설정 |
| 최종 양성 비율 | 생성 후 확인 | 생성 후 확인 |

예를 들어 다음과 같은 방식으로 관리할 수 있습니다.

- NOx: 근접 진입, 급격한 상승, 완만한 상승 시나리오를 조합하여 생성
- SO₂: 실제 데이터에서 부족한 임계치 진입 및 급격한 상승 패턴을 별도로 보완
- 두 물질 모두 생성 후 Label 자동 산출 결과를 기준으로 양성·음성 비율 확인

첨부 시나리오에 있는 NOx 45%, SO₂ 23% 등의 복귀 확률은 실제 데이터에서 산출한 값인지, 합성데이터 생성 시 임의로 설정한 값인지 구분해야 합니다. 실제 데이터에서 확인되지 않은 확률이라면 검증된 통계값처럼 사용하지 말고 생성 파라미터로 관리하는 것이 좋습니다.

### 2.4 합성데이터와 실제 데이터의 혼합

합성데이터는 실제 데이터에서 부족한 양성 패턴을 보완하기 위한 용도로 활용합니다.

다만 합성데이터의 양성 비율을 높였다고 해서 실제 데이터의 분포까지 변경해서는 안 됩니다.

권장하는 데이터 구성은 다음과 같습니다.

| 구분 | 데이터 구성 | 목적 |
|---|---|---|
| Train | 실제 데이터 + 합성데이터 | 학습 데이터 부족 및 클래스 불균형 보완 |
| Validation | 실제 데이터 중심 | 모델 및 Threshold 조정 |
| Test | 실제 데이터 | 최종 성능 평가 |

실제 데이터와 합성데이터를 Train에 혼합할 경우, 합성데이터가 특정 시나리오에 과도하게 편중되지 않도록 관리해야 합니다.

또한 시간 기준으로 Train/Validation/Test를 먼저 분리하고, 합성데이터 생성 및 샘플링이 평가 데이터의 정보를 참조하지 않도록 해야 합니다.

Validation과 Test는 가능한 한 실제 운영 환경의 양성 비율과 데이터 특성을 유지해야 합니다. 합성데이터가 포함된 평가 결과만으로 실제 운영 성능을 판단해서는 안 됩니다.

### 2.5 합성데이터 생성 결과 확인 항목

합성데이터를 생성한 후에는 전체 생성 건수뿐 아니라 실제 Label 생성 결과를 확인해야 합니다.

| 확인 항목 | 확인 내용 |
|---|---|
| 전체 생성 건수 | NOx·SO₂별 생성 데이터 수 |
| 시나리오별 생성 건수 | S-01~S-13별 데이터 수 |
| 양성 건수 | Label 1로 생성된 데이터 수 |
| 음성 건수 | Label 0으로 생성된 데이터 수 |
| 제외 건수 | Label NULL 데이터 수 |
| 양성 비율 | NOx·SO₂별 양성 비율 |
| 시나리오별 양성 비율 | 각 시나리오에서 실제 양성으로 판정된 비율 |
| 실제·합성 비율 | 학습 데이터에서 실제 데이터와 합성데이터의 구성 비율 |

특히 시나리오별 생성 건수와 실제 양성 Label 건수를 구분해서 관리해야 합니다.

예를 들어 S-05 데이터를 10만 건 생성했다고 해서 양성 데이터가 10만 건 증가하는 것은 아닙니다. 각 시점의 향후 60분 측정값을 기준으로 Label을 산출해야 실제 양성 건수를 확인할 수 있습니다.

### 2.6 최종 권장 방향

합성데이터는 다음 순서로 활용하는 것을 권장합니다.

1. 실제 데이터에서 NOx·SO₂별 양성 비율과 부족한 패턴을 분석합니다.
2. 부족한 패턴을 중심으로 S-01~S-13 시나리오를 생성합니다.
3. 생성된 측정값에 현재 분류 Label 기준을 적용하여 `0`, `1`, `NULL`을 자동 산출합니다.
4. 시나리오별 양성·음성·제외 건수를 확인합니다.
5. 실제 데이터와 합성데이터를 Train에 혼합합니다.
6. 실제 데이터 중심의 Validation/Test로 모델 성능을 검증합니다.
7. 합성데이터 적용 전후 Recall, Precision, PR-AUC를 비교합니다.

**핵심은 합성데이터의 양을 늘리는 것이 아니라, 실제 데이터에서 부족한 양성 패턴을 보완하면서도 실제 운영 환경의 데이터 특성과 Label 기준을 유지하는 것입니다.**
