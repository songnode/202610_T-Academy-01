# 시간 주기 변환 (Cyclical Time Encoding)

## 1. 개념

시간 주기 변환은 시간 정보를 AI 모델이 이해하기 쉽도록 숫자로 변환하는 Feature Engineering 기법입니다.

시간은 24시간, 12개월처럼 반복되는 특성이 있습니다. 이러한 순환적인 특성을 반영하기 위해 Sin과 Cos 함수를 사용합니다.

## 2. 변환이 필요한 이유

시간을 숫자로 그대로 사용하면 다음과 같은 문제가 있습니다.

| 시간 | 숫자 |
|---|---:|
| 23:00 | 23 |
| 00:00 | 0 |
| 01:00 | 1 |

숫자상으로는 23시와 0시의 차이가 크지만, 실제로는 1시간 차이입니다.

Sin과 Cos를 이용하면 23시와 0시가 서로 가까운 시간이라는 특성을 모델에 전달할 수 있습니다.

## 3. 변환 공식

하루 24시간을 기준으로 변환합니다.

\[
hour\_sin = \sin\left(\frac{2\pi \times hour}{24}\right)
\]

\[
hour\_cos = \cos\left(\frac{2\pi \times hour}{24}\right)
\]

예를 들어 09:00은 다음과 같이 변환됩니다.

```python
hour_sin = 0.707
hour_cos = -0.707
```

월 정보도 동일한 방식으로 12개월 주기를 적용합니다.

## 4. TMS 프로젝트 적용

TMS 프로젝트에서는 시간대 및 계절에 따른 배출량 변화 패턴을 학습하기 위해 다음 5개 Feature를 사용합니다.

| Feature | 설명 |
|---|---|
| `hour_sin` | 시간의 Sin 변환값 |
| `hour_cos` | 시간의 Cos 변환값 |
| `month_sin` | 월의 Sin 변환값 |
| `month_cos` | 월의 Cos 변환값 |
| `day_of_week` | 요일 정보 |

시간 정보는 대만 현지 시간(`Asia/Taipei`)을 기준으로 계산합니다.

**핵심:** 시간 정보를 단순한 숫자로 사용하는 대신 Sin과 Cos로 변환하여 시간대와 계절에 따른 반복적인 패턴을 AI 모델이 학습하도록 하는 것입니다.
